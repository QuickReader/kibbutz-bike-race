# Kibbutz Bike Race

Blocky 3D bike race through a kibbutz, from a house to the dining hall. Dodge the people walking. Phone, landscape.

Run locally: `python3 -m http.server 8000`, open http://localhost:8000 (arrow keys on desktop).

Privacy: this game collects no data. It is hosted on GitHub Pages, which may log visits under GitHub's own privacy policy.
